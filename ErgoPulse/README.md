# ErgoPulse 🧠💪  
_A healthy reminder tool for desk workers — built with Python + Tkinter_

ErgoPulse helps you take regular breaks, stretch, and rest your eyes while working long hours at your desk.  
It reminds you to **stand up, walk for a few minutes, and do simple eye exercises** (20-20-20 rule).  
Each reminder also shows **current time, a motivational quote, and optional weather updates**.

---

## ✨ Features
- ⏰ **Smart Intervals** — set reminders every 30/40 minutes (customizable)  
- 🚶 **Break Notifications** — 5-min walk & 20-20-20 eye exercise reminder  
- 🧘 **Quotes & Motivation** — displays a random motivational quote each cycle  
- ❌ **Auto-Close Notifications** — notification disappears after N seconds  
- 🔄 **Skip / Snooze** — snooze break for 2 minutes or skip it  
- 📝 **Session Logs** — tracks how many breaks you’ve taken (CSV logs)  
- 🕗 **Quiet Hours** — no reminders at night (customizable)  
- 🍅 **Pomodoro Mode** (25/5 or 50/10) — optional productivity style
