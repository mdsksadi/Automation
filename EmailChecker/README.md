# Auto Email Checker
### A Modern Python GUI for Reading, Sending & Managing Emails (Gmail + Outlook)

## Overview
**Auto Email & Notification Checker** is a desktop application built using **Python** and **CustomTkinter** that allows to:
- Check **unread emails** from **Gmail** and **Outlook**
- View sender, subject, and date in a clean **GUI table**
- **Mark emails as read**
- **Compose & send** new emails directly from the app
- See **real-time terminal-style logs** at the bottom of the app
- Automatically **refresh emails in the background**
- built in **Terminal** will show the workflow
